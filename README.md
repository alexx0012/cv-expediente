## 🔎 02. Sobre el proyecto

¿Y si un currículum fuera un expediente que pudieras abrir y explorar?

CV-Expediente es un proyecto personal que transforma un currículum tradicional en una experiencia web interactiva inspirada en las carpetas policiales, los documentos clasificados y los archivos físicos antiguos.

La interfaz reproduce una carpeta de cartón envejecido que el visitante puede abrir para descubrir los distintos documentos que componen mi trayectoria profesional.

El objetivo es combinar diseño visual, animaciones, accesibilidad y desarrollo web en un proyecto propio que refleje mi aprendizaje y evolución como desarrollador.

## ⚙️ 04. Características principales

- 📂 **Carpeta interactiva:** apertura y cierre mediante animaciones.
- 📄 **Documentos independientes:** navegación entre las páginas del expediente.
- 🧩 **Web Components:** componentes personalizados y reutilizables.
- 🛡️ **Shadow DOM:** encapsulación de estilos y estructura.
- 📱 **Diseño responsive:** adaptación a escritorio y dispositivos táctiles.
- ⌨️ **Navegación por teclado:** controles para avanzar, retroceder y cerrar el expediente.
- ♿ **Accesibilidad:** gestión del foco, etiquetas accesibles y respeto por la preferencia de movimiento reducido.
- 🚀 **Vite:** entorno de desarrollo y compilación optimizada para producción.

## 💻 06. Instalación y ejecución

### Requisitos previos

- Node.js
- pnpm

### 1. Clonar el repositorio

```bash
git clone https://github.com/alexx0012/cv-expediente.git
cd cv-expediente
```

### 2. Instalar las dependencias

```bash
pnpm install
```

### 3. Iniciar el servidor de desarrollo

```bash
pnpm dev
```

Vite mostrará en la terminal la dirección local para abrir el proyecto en el navegador.

### 4. Generar la versión de producción

```bash
pnpm build
```

Los archivos optimizados se generarán en el directorio `dist/`.

### 5. Previsualizar la versión compilada

```bash
pnpm preview
```
